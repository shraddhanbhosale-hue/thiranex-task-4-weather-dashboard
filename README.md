# Thiranex Task 4 - Weather Dashboard

A responsive and interactive Weather Dashboard developed as part of the **Thiranex Web Development Internship - Task 4**.

The application uses asynchronous JavaScript and a public REST API to fetch and display real-time weather information based on the city entered by the user.

## Features

- Search weather by city name
- Fetch real-time weather data
- Display current temperature
- Display weather condition
- Display humidity
- Display wind speed
- Dynamic DOM updates
- Fetch API integration
- Async/await
- JSON data processing
- Error handling for invalid cities
- Network error handling
- Loading state
- Responsive design
- User-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- REST API
- JSON
- DOM Manipulation

## API Used

This project uses the **Open-Meteo API** to retrieve weather information.

Open-Meteo provides weather data without requiring an API key for normal usage.

The application uses:

- Geocoding API to find the coordinates of a city
- Forecast API to retrieve current weather data
